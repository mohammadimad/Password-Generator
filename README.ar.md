# مولّد كلمات مرور عشوائية

تطبيق صغير يعمل في المتصفح ويولّد اقتراحين لكلمات المرور في كل مرة. بُني للتدرّب على مصفوفات JavaScript والحلقات والاختيار العشوائي والدوال وتحديث DOM ضمن واجهة بسيطة ومتجاوبة.

## المزايا

- توليد اقتراحين لكلمات المرور بنقرة واحدة.
- إنشاء كلمات مرور بطول 15 محرفًا.
- استخدام الأحرف الإنجليزية الكبيرة والصغيرة والأرقام والرموز.
- استبدال النتائج السابقة عند كل عملية توليد.
- تكييف عرض النتائج مع الشاشات الضيقة.

## التقنيات المستخدمة

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## التشغيل محليًا

لا يحتاج المشروع إلى تثبيت حزم أو عملية بناء.

```bash
git clone https://github.com/mohammadimad/Password-Generator.git
cd Password-Generator
```

افتح `index.html` في المتصفح، أو شغّل المجلد بواسطة خادم تطوير محلي.

## آلية العمل

تحتوي مصفوفة `characters` على الأحرف والأرقام والرموز المتاحة. عند تشغيل `Generateor()`، تُمسح النتيجتان السابقتان، ثم يُختار 15 محرفًا عشوائيًا لكل كلمة مرور وتُحدّث الصفحة باستخدام `textContent`.

## بنية المشروع

```text
.
|-- index.html    # واجهة المولّد
|-- index.css     # تصميم البطاقة المتجاوب
`-- index.js      # مجموعة المحارف ومنطق التوليد
```

## ملاحظة أمنية

يستخدم المشروع `Math.random()` لأغراض تعليمية، ولذلك لا تُعد نتائجه آمنة تشفيريًا ولا ينبغي استخدامها لإنشاء كلمات مرور لحسابات حقيقية حساسة. يجب أن يستخدم التطبيق الإنتاجي Web Crypto API مثل `crypto.getRandomValues()`.

## تحسينات مقترحة

- استخدام مصدر عشوائي آمن تشفيريًا.
